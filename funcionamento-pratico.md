# Funcionamento Prático dos Malwares

## Keylogger

Um Keylogger é uma ferramenta desenvolvida para registrar teclas digitadas em um computador.

### Funcionamento

- Opera em segundo plano
- Captura teclas digitadas
- Armazena informações sensíveis
- Pode enviar dados para um servidor remoto

### Tipos

- Keylogger de software
- Keylogger de hardware

### Objetivos comuns

- Roubo de senhas
- Captura de cartões
- Espionagem

---

## Ransomware

O Ransomware sequestra dados do usuário através de criptografia.

### Ciclo de ataque

1. Execução do malware
2. Geração de chave criptográfica
3. Busca por arquivos
4. Criptografia dos dados
5. Pedido de resgate

### Tipos

- Crypto-ransomware
- Locker-ransomware
- Leakware
